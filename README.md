# Brooke's Christmas Gift Blaster

A private Christmas browser game. Everything is in `index.html`; no build step needed.

## Put it online with GitHub Pages
1. Create a new repository (for example `brooke-christmas-blaster`).
2. Upload every file in this folder to the repository's main branch, including `.nojekyll`.
3. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", choose **main** and **/(root)**, then **Save**.
4. After a minute or two the game is live at `https://YOUR-USERNAME.github.io/brooke-christmas-blaster/`.

## Files
- `index.html` — the whole game (art, music, recorded voices)
- `manifest.webmanifest` and `icon-xmas-*.png` — Home Screen icon and full-screen settings
- `.nojekyll` — tells GitHub Pages to serve the files exactly as they are
